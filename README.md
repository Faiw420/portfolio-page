# Tim Darmstaedter – Portfolio

Personal site built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com) v4, deployed as a
Cloudflare Worker. All pages are static assets; only `/stats` and `/api/stats/*` run in the Worker and proxy a
self-hosted [Umami](https://umami.is) instance (responses are cached at the edge for 30–60 s).

## Develop

```bash
npm install
cp .dev.vars.example .dev.vars   # Umami credentials for the Stats page
npm run dev
```

## Structure

- `src/lib/site.js` – navigation, keyboard shortcuts (`1…n` pages, `0` theme) and profiles
- `src/data/` – page content (work, journey, stack)
- `src/pages/` – routes; `api/stats/*` are server endpoints
- `src/styles/global.css` – design tokens (light/dark) and base styles

## Social preview image

`public/og.png` is generated by `npm run og` (`scripts/og.mjs`). Re-run it after changing name, role or portrait.

## Deploy (Cloudflare Workers)

```bash
npx wrangler login
npx wrangler secret put UMAMI_API_URL      # repeat for UMAMI_WEBSITE_ID, UMAMI_USERNAME, UMAMI_PASSWORD
npm run deploy
```

The site URL (`https://darmstaedtert.im`) is set in `astro.config.mjs`; `SITE_URL` overrides it at build time. The custom domain is attached
in `wrangler.jsonc` (`routes` with `custom_domain: true`). Test the production build locally with `npm run preview`.
